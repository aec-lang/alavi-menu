# چلوکبابی علوی — اپ منو (Android)

منوی موبایلی چلوکبابی علوی: صفحه‌های جدا برای غذاها، نوشیدنی‌ها و سینی‌های چلوکبابی علوی،
ساخت خودکار عکس سینی روی عکس واقعی سینی خالی، فاکتور با شماره/تاریخ/متن دلخواه،
و ذخیره عکس فاکتور در گالری (Pictures/AlaviFood) با پل بومی `Android.saveImage`.

ساخته‌شده با Capacitor 6 + WebView. بیلد خودکار با GitHub Actions
(`.github/workflows/build-apk.yml`) و خروجی APK دیباگ.
